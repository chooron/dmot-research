## 3. Script Generating the Manifest
- `scripts/export_citable_numbers_f3.py`: exports the freeze-ready citable list (status RECOMPUTED or RE-VERIFIED)
  and the excluded list (SUPERSEDED / LOADED / SENSITIVITY, each with an exclusion reason) from the master manifest.
- `scripts/compile_master_manifest.py`: dynamically scans all unit tables and compiles master manifest.
- `scripts/compile_manifest_provenance.py`: generates this provenance file.

## 4. Hard Requirement Compliance

## 5. Results Registry S3 Numeric-N Declaration Exception
- The Results-registry `population_taxonomy.csv` is the definition-level inventory of numeric population N values and is an explicitly approved exception to the no-numeric-values rule for declarations.
- Its numeric N values are generated by the registry/evidence scripts from `E5_population_N_evidence.csv` and source-table-backed population overrides; they are not manually transcribed.
- This exception is limited to the population-N taxonomy. Sign, direction, primary/secondary, and quantity-class declarations remain free of numeric estimates.
- The source population-N overrides state category and meaning only; scripts parse the numeric values from the cited source tables.
